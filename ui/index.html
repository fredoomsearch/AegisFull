          Guía rápida de AEGIS
          
          
        
          
        
          
          
            
            
          • 💬 Chat: conversación normal con memoria. Usa modo Código/Cripto si aplica.
            • 
            
          • 🌐 Modo Web: botón globo; llama a /websearch y muestra fuentes a la derecha.
            • 
            
          • 🔗 Modo URL: pega una URL; /fetch_url la lee y la ves en Fuentes.
            • 
            
          • 🧠 Modo Código: envía preguntas técnicas; usa RAG si hay índice.
            • 
            
          • 🖼️ Imagen: sube una imagen; /analyze_image hace OCR local (ES/EN).
            • 
            
          • 📈 Cripto (señal + horizonte): escribe “BTCUSDT H=2m” o usa el panel Cripto. Genera señal demo y guarda precio base.

          Despliegue rápido y símbolos (USDT)
          
          
        
          
        
          
          
          Deploy (local): activa DB + claves, luego uvicorn main:app --reload. Usa el ícono de llave para poner la misma clave en la UI.
          
          
          Claves mínimas: ADMIN_API_KEY, AEGIS_API_KEY, FILES_API_KEY, DATABASE_URL. Opcional: NEWSAPI_TOKEN, CRYPTOPANIC_TOKEN, CRYPTO_NEWS_RSS.
